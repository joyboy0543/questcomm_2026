
# QuestComm — Full Update Pack (Landing + Responsive + Bonus UI + Mini-games)

## How to apply (recommended via PR)
1) Create a branch:
   git checkout -b feature/full-update
2) Copy all files from this pack into your repo root (preserve paths).
3) Commit & push:
   git add -A
   git commit -m "feat: full UI update + landing + responsiveness"
   git push -u origin feature/full-update
4) Open a Pull Request to `main`. After merge, GitHub Pages redeploys automatically.
   If you see the old version, hard-refresh (Ctrl/Cmd+Shift+R).

## Notes
- Add small OGGs under assets/sounds/ and an optimized GIF under assets/img/.
- You can require PR reviews with Branch Protection in Settings → Branches.
